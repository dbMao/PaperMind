# PaperMind 前端交互布局规范

## 整体布局

应用为单页 SPA，路由 `"/"` 即主工作台。不使用多页面路由跳转。

---

## 状态一：初始状态（未选中论文）

```
┌──────────────┬──────────────────────────────────────────┐
│              │                                          │
│   论文库      │          初始欢迎页                      │
│  （左侧 20%） │        （右侧 80%）                      │
│              │                                          │
│  ┌──────────┐│    ┌──────────────────────────┐          │
│  │ 上传论文  ││    │                          │          │
│  │ [按钮]   ││    │      📚 PaperMind        │          │
│  ├──────────┤│    │                          │          │
│  │ 搜索框   ││    │   欢迎使用论文阅读助手    │          │
│  ├──────────┤│    │                          │          │
│  │ 论文列表  ││    │  上传论文或选择一篇论文   │          │
│  │ - 论文1  ││    │      开始智能阅读         │          │
│  │ - 论文2  ││    │                          │          │
│  │ - 论文3  ││    │                          │          │
│  │          ││    └──────────────────────────┘          │
│  │          ││                                          │
│  └──────────┘│                                          │
└──────────────┴──────────────────────────────────────────┘
   left: 1 (20%)              right: 4 (80%)
```

### 左侧：论文库 (1/5)

- **顶部**：上传按钮（支持拖拽和文件选择器）
- **搜索框**：按标题关键词实时过滤
- **论文列表**：
  - 每项显示：标题、作者、年份、上传时间
  - 鼠标悬停显示操作按钮（删除）
  - 点击选中论文 → 切换到状态二

### 右侧：欢迎页 (4/5)

- 应用 Logo / 图标
- 简短欢迎语
- 空状态提示引导用户操作

## 状态二：选中论文后

```
┌──────────────────────┬──────────────────────────────────┐
│                      │  ┌────────────────────────────┐  │
│   论文内容展示        │  │  AI 回复区域               │  │
│  （左侧 66%）         │  │  （右上半区 5/7）           │  │
│                      │  │                            │  │
│  ┌──────────────────┐│  │  [AI 回答内容 ...]         │  │
│  │ 论文标题          ││  │                            │  │
│  │ 作者 · 年份       ││  │                            │  │
│  ├──────────────────┤│  │                            │  │
│  │                  ││  ├────────────────────────────┤  │
│  │  论文正文内容     ││  │  用户输入框               │  │
│  │  （可选中文字）   ││  │  （右下区 2/7）            │  │
│  │                  ││  │  ┌────────────────────────┐│  │
│  │                  ││  │  │ 输入问题 ...    [发送] ││  │
│  │                  ││  │  └────────────────────────┘│  │
│  │                  ││  └────────────────────────────┘  │
│  └──────────────────┘│                                  │
│                      │                                  │
└──────────────────────┴──────────────────────────────────┘
   left: 2 (≈66%)             right: 1 (≈33%)
```

### 左侧：论文内容 (2/3)

- **顶部**：论文元信息栏（标题、作者、年份、标签）
- **按钮栏**：生成摘要、对比分析（多选时可用）
- **正文区域**：论文解析后的文本内容，分段落展示
- **划词交互**：选中文字后弹出悬浮按钮 “基于此提问”，点击后将选中文字发送到右侧对话框

### 右侧：对话框 (1/3)

- **上半区 (5/7)**：AI 回复区域
  - 对话气泡形式（用户消息靠右，AI 回复靠左）
  - AI 回复中引用来源可点击跳转到左侧对应段落高亮
  - 支持流式输出（逐字显示）
  - 顶部显示当前对话模式标签（单篇 / 全局）
  - 自动滚动到最新消息

- **下半区 (2/7)**：用户输入区
  - 多行文本输入框（支持 Shift+Enter 换行，Enter 发送）
  - 发送按钮
  - 模式切换按钮（单篇 vs 全局）

## 全局组件

### 顶部导航栏（可选，简洁版）

```
┌──────────────────────────────────────────────────────────┐
│  PaperMind      [首页]           [设置] [模型状态指示灯] │
└──────────────────────────────────────────────────────────┘
```

- 设置页：路由 `/settings`，独立页面
- 模型状态灯：绿色（已配置且可用）/ 黄色（未测试）/ 红色（连接失败）

### 上传对话框

```
┌──────────────────────────────┐
│  上传论文                     │
│                              │
│  ┌──────────────────────────┐│
│  │   拖拽 PDF 到此处        ││
│  │   或点击选择文件          ││
│  └──────────────────────────┘│
│                              │
│  ☐ 启用 AI 增强语义解析      │
│     (将消耗额外 tokens)      │
│                              │
│  [取消]           [上传]     │
└──────────────────────────────┘
```

## 响应式适配（后续迭代）

- **桌面端（≥1200px）**：默认布局
- **平板端（768px-1199px）**：论文库可折叠为左侧图标栏
- **移动端（<768px）**：论文库和对话框分页切换
